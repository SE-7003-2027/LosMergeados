Descripción del proyecto

Este proyecto consiste en desarrollar un sistema de recomendación de libros, cómics y manga disponibles en México.

La idea es que el sistema pueda utilizar información sobre las preferencias y valoraciones de los usuarios para generar recomendaciones que se adapten a sus intereses.

Durante el desarrollo iremos definiendo los requerimientos, fuentes de datos, algoritmos de recomendación y arquitectura necesarios para construir el sistema.

Objetivo

Desarrollar una aplicación capaz de proporcionar recomendaciones personalizadas de libros, cómics y manga, utilizando las preferencias y valoraciones de los usuarios.
